# Voyager Academy

Standalone educational trading platform — beginner to advanced content,
built to eventually link from Voyager Analytics' main nav and landing page.

## Structure
- `content/lessons/` — one markdown file per lesson, sourced from trading
  book material as it comes in
- `js/courses-data.js` — the index of all lessons/tracks; add an entry here
  whenever a new lesson file is added
- Rename "Voyager Academy" and swap `--va-gold` in `css/variables.css`
  if you want a different brand identity than the placeholder used here

## Not yet built
- `lesson.html` content-loading template
- `community.html` (forum/discussion placeholder)
- `about.html`
- Actual lesson content (pending your trading book source material)
